# Stroke Prediction using Machine Learning
Predict whether a patient will have a stroke based on clinical and demographic features (classification problem)

## Project Flow
- Data Cleaning & Preprocessing  
- Exploratory Data Analysis (EDA)  
- Model Training (Linear Regression, Random Forest, etc.)  
- Model Evaluation  
- Predictions  

## Tech Stack
- Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn 

## Dataset
[Kaggle Dataset](https://www.kaggle.com/code/rishabh057/healthcare-dataset-stroke-data/input)
